# Comic Game

An interactive educational space-mission game for children. Players explore a comic-book-style mission book and complete activities such as matching, memory, puzzles, and story challenges.

## Features

- Interactive comic-book mission experience
- Multiple educational mini-games
- Progress tracking across missions
- English and Bangla localization
- Responsive React interface with custom artwork and fonts

## Tech stack

- React 19
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Then open the local URL shown by Vite.

## Available scripts

```bash
pnpm dev       # Start the development server
pnpm build     # Create a production build
pnpm preview   # Preview the production build locally
pnpm format    # Format the project
```

## Project structure

- `src/` - Main React application, components, assets, data, and localization
- `app/` - Additional page entry points
- `public/` - Static public assets, when applicable
